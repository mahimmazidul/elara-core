# Prospective analysis plan for the Utah model adjustment

This plan was written before inspecting the participant split or candidate results. The original baseline report describes aggregate results from the entire Utah cohort, so even the held-out partition is not a wholly pristine external benchmark.

1. Keep the original next-start walk-forward preparation and all eligible outcomes, including long cycles. Deterministically assign each participant to development or holdout using `split_cases.py` (SHA-256 prefix `elara-person-split-2026-11-v1:`, buckets 0–6 development and 7–9 holdout). A participant cannot occur in both partitions.
2. Select a simple, bounded personal-history adjustment using **development participants only**. Candidate point forecasts are the existing default fused integer, blended with a shrinkage estimate based on the median of all previously completed cycle lengths. Candidate priors are 28, 29 and 30 days; shrinkage strengths are 1, 2 and 4 prior cycles; blend weights are 0.25, 0.50, 0.75 and 1.00. No adjustment is made when there is no completed cycle. Limit the change to at most three days in either direction relative to the old fused point. The input is exclusively historical starts. The existing uncertainty radius and heuristic confidence are not altered by this point-only adjustment.
3. Select the candidate with the lowest forecast-weighted development MAE. Break exact ties by preferring the smaller blend weight, then the larger shrinkage strength, then the prior closest to 29 days. Preserve the unadjusted default as a comparator.
4. Evaluate the frozen selected candidate once on the holdout using the actual Dart implementation. Consider adopting it as the default only if holdout MAE improves by at least 0.03 days, coverage and ±3-day accuracy each decline by no more than one percentage point, and there is no material degradation in sizeable history/variability slices. Report a participant-cluster bootstrap interval for the paired MAE difference. The bootstrap is descriptive, and no significance is guaranteed.
5. Report both positive and negative outcomes, interval widths, sample sizes and licensing. Do not tune on the separate Marquette dataset because its commercial-use rights have not been established. Do not commit participant-level cases, predictions or data. If the candidate does not pass the gates, keep the existing default and report that the attempted improvement was not demonstrated.
